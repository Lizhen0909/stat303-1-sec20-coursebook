1. Air Quality Sensors (30 points)

An application of broadcasting.

Air quality sensors measure the amount of contaminants in air. This question finds locations for 50 air quality sensors in Colorado so that they are as far from each other as possible. The method below is a greedy algorithm that finds an approximate maximin design.

The file data/colorado_coordinate_grid.txt holds the coordinate-pairs (latitude and longitude) of potential sensor locations. A coordinate-pair means a latitude-longitude pair, and “air quality sensor” is shortened to “sensor” below. Measure every distance as the Euclidean distance between coordinate-pairs.

The starter notebook supplies this function, which draws the sensors in air_sensor_coordinates on a map of Colorado:

import matplotlib.pyplot as plt

def sensor_viz():
    """Draw the sensors in air_sensor_coordinates on the map of Colorado."""
    img = plt.imread("data/colorado.jpg")
    fig, ax = plt.subplots(figsize=(10.5, 7.7))
    ax.imshow(img, extent=[-109, -102, 37, 41])
    ax.scatter(-air_sensor_coordinates[:, 1], air_sensor_coordinates[:, 0], color="blue")
    ax.set(xlim=(-109.05, -101.95), ylim=(36.95, 41.05),
           xlabel="Longitude", ylabel="Latitude")
    plt.show()

1.1 Read the grid (2 points)

Read the file with NumPy, skipping its header row. How many coordinate-pairs are there?

Hint: np.genfromtxt() with delimiter=",", as in NumPy Fundamentals. The file’s first line holds the column names, Latitude,Longitude, so also pass skip_header=1, which skips that line; otherwise it is read as a row of nan values.

1.2 First sensor (2 points)

The first sensor goes at the grid point closest to Denver, whose coordinate-pair is 39.7392° N, 104.9903° W. The file omits the ° N and ° W, so Denver is [39.7392, 104.9903] in its units. Find the coordinate-pair of the first sensor.

Hint: Broadcasting. grid - denver subtracts Denver’s coordinate-pair from every row at once, ** 2 squares every entry, and np.sqrt() takes the square root element-wise, the way np.round() did in NumPy Fundamentals. Sum the squared differences across each row before taking the square root.

1.3 Second sensor (4 points)

The second sensor goes at the grid point farthest from the first sensor. Find its coordinate-pair.

Hint: Broadcasting.

1.4 The first two sensors (4 points)

Stack the coordinate-pairs of the first and second sensors vertically into a 2 × 2 NumPy array named air_sensor_coordinates. Then run the supplied sensor_viz() to check your work: the two sensors appear as blue dots on the map.

1.5 Third sensor (12 points)

The third sensor goes at the grid point that is farthest from the sensors already placed. Proceed as follows:

  1. For each coordinate-pair in the grid, find its minimum distance from the two sensors already placed. For example, a point 5 units from the first sensor and 10 units from the second has a minimum distance of \(\min(5, 10) = 5\).
  2. Select the coordinate-pair whose minimum distance is the largest.
  3. Stack it vertically onto air_sensor_coordinates, and call sensor_viz() to check that three sensors appear.

Hint: Write a function that takes one coordinate-pair and returns its minimum distance from all the rows of air_sensor_coordinates. Then apply it to every row of the grid with np.apply_along_axis(function, 1, grid), which calls the function once per row (axis 1) and collects the results in an array.

1.6 All 50 sensors (6 points)

Generalize Question 1.5 to place 47 more sensors. With \(i\) sensors placed, find each grid point’s minimum distance from those \(i\) sensors, \(\min(d_1, d_2, \ldots, d_i)\), and place sensor \(i + 1\) at the grid point where that minimum is largest. Repeat until there are 50 sensors. This is one of the two questions where a loop is allowed.

Call sensor_viz() at the end: you should see 50 blue dots spread across Colorado.

2. Seasonal Sales (16 points)

An application of matrix multiplication.

When the monthly sales of a product rise and fall with the seasons, a curve that approximates the sales might have the form

\[y = a + b\,x + c\,\sin\left(2\pi\,\frac{x}{12}\right),\]

where \(x\) is the number of months since the starting point and \(y\) is the monthly sales in millions of US dollars. The term \(a + b\,x\) gives the basic trend and the sine term the seasonal change. For a brand of sunscreen whose sales are counted from June 2017 (so June 2017 is \(x = 1\)), the estimated parameters \(a\), \(b\), and \(c\) are supplied in the starter as model_parameters = [2, 5, 18].

Estimate the total sales for every month from June 2017 through February 2020, inclusive, with matrix multiplication. (Many sales models failed after March 2020, probably because of COVID.)

2.1 The months array (8 points)

Create a NumPy array with one row per month in the period and three columns: all 1s; the month number \(x\), from 1 to the number of months in the period; and \(\sin(2\pi x / 12)\) for each \(x\).

Hint: np.sin() applies the sine to every entry of an array at once, like the other NumPy functions in NumPy Fundamentals, and np.pi is the constant \(\pi\). Build the three columns as 1D arrays, then combine them with np.vstack() and .T from the same chapter.

2.2 The parameters array (2 points)

Create a NumPy array from model_parameters.

2.3 Monthly sales (4 points)

Use matrix multiplication to get the estimated sales for each month in the period.

2.4 Total sales (2 points)

Find the total estimated sales over the whole period.

3. Starbucks Drinks (33 points)

An application of matrix and element-wise operations.

data/starbucks-menu-nutrition-drinks.csv holds the nutrition facts of each Starbucks drink. data/starbucks_DrinkType_USStates.csv holds how many of each drink are consumed in each US state per 10,000 people. Both files list the same drinks in the same order, one row per drink.

Some drink names appear on two rows, because the menu lists two versions of those drinks with different nutrition facts. Treat every row as a separate drink, and when a question asks for a drink, report its name and its row position. Read the files with pandas, convert the numeric columns to NumPy arrays, and answer every question with NumPy operations.

3.1 Most consumed drink and highest-consuming state (8 points)

  1. Which drink is consumed the most across all states combined? Report its name and row position.
  2. Which state has the highest total consumption, summed over all drinks?

(4 points each.) Hint: sum() with an axis, and argmax(). To turn a column position into a state name, df.columns[position] returns the name of the column at that position.

3.2 Highest total-fat drink in Illinois (10 points)

A drink’s total fat is the sum of its saturated, unsaturated, and trans fat. Considering consumption in Illinois only, which drink accounts for the most total fat consumed? Report its name and row position.

3.3 Lowest fat and highest protein states (10 points)

Using matrix multiplication, compute each state’s total fat consumption and total protein consumption per 10,000 people. Which state consumes the least total fat, and which consumes the most protein?

(5 points each.) Hint: argmin() and argmax() give positions; name the states with df.columns[position], as in Question 3.1.

3.4 Protein more than twice fat (5 points)

Using the arrays from Question 3.3, count the states whose protein consumption is more than twice their total fat consumption. Use only NumPy array operations; do not add columns to a DataFrame.

Hint: A comparison gives a Boolean array, and summing it counts the True values.

4. Exercise Minutes (16 points)

An application of vectorized random sampling.

The list exercise_minutes, supplied in the starter, holds the weekly exercise minutes reported by students in a past STAT 303-1 class. This question finds a 95% confidence interval for the mean with bootstrapping, twice — once in plain Python and once with NumPy — and compares the time each takes.

The bootstrap method:

  1. Let \(N\) be the number of values in exercise_minutes.
  2. Draw \(N\) values at random, with replacement, from exercise_minutes.
  3. Compute the mean of those \(N\) values.
  4. Repeat steps 2 and 3 10,000 times.
  5. The 95% confidence interval runs from the 2.5th to the 97.5th percentile of the 10,000 means.

The starter notebook supplies exercise_minutes as a Python list of 191 values.

4.1 Without NumPy (8 points)

Without NumPy, compute the confidence interval, and time the computation. This is the other question where a loop is allowed.

Hints: random.choices(exercise_minutes, k=N), from Python’s built-in random module (import random), draws \(N\) values with replacement. With the 10,000 means in a sorted list, the 2.5th and 97.5th percentiles are approximately the values at positions 250 and 9,750. Time the cell with %timeit -o -r 3 -n 1, as in NumPy and pandas in a Real Workflow, and keep the result’s .average.

4.2 With NumPy (7 points)

Using NumPy and no loops, compute the same confidence interval and time it the same way.

Hint: rng = np.random.default_rng(303), then rng.choice(), which draws with replacement by default, as in NumPy Fundamentals. Passing a tuple, size=(10_000, N), returns a 2D array with one bootstrap sample per row, so .mean(axis=1) gives all 10,000 means at once. np.percentile() with [2.5, 97.5] gives both percentiles, as in the Aggregate Functions section.

4.3 Time saved (1 point)

Report the ratio of the time without NumPy to the time with NumPy.
