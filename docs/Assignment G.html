1. Projects and Missing Values (27 points)

data/Canadian_Fish_Biodiversity.csv holds 8,387 rows from a 2013 survey of fish populations in Ontario, Canada. Each row records one species caught in one fishing event. Each site (SITEID) is a time and place where fishing took place, and sites are grouped into broader projects (Project Name).

If a question updates the dataset, for example by imputing missing values or adding a column, use the updated dataset in the questions that follow.

The starter supplies the code that reads the data:

fish = pd.read_csv("data/Canadian_Fish_Biodiversity.csv")

1.1 Top three projects (4 points)

Using groupby(), find the three projects with the most unique sites.

1.2 Number of missing air temperatures (1 point)

How many values of Air Temperature (C) are missing?

1.3 Imputation, attempt 1 (4 points)

Impute the missing air temperatures with the median air temperature of the rows with the same Waterbody Name and Month.

Hint: groupby() with two columns and transform("median"), from Data Aggregation.

1.4 Missing values after attempt 1 (1 point)

How many air temperatures are still missing after Question 1.3? Explain why the imputation could not fill them.

1.5 Imputation, attempt 2 (4 points)

Impute the remaining missing air temperatures with the median air temperature of the rows with the same Project Name and Month.

1.6 Missing values after attempt 2 (1 point)

How many air temperatures are still missing after Question 1.5?

1.7 Air and water temperature (1 point)

Find the correlation between Air Temperature (C) and Water Temperature (C).

1.8 Missing values after a hypothetical attempt 3 (3 points)

Because the two temperatures are highly correlated, you could impute the remaining air temperatures from water temperature with a trendline, as in Data Cleaning. Do not do this imputation. Assuming you did, how many air temperatures would still be missing? Explain.

1.9 Visualizing the imputation (8 points)

Make a scatterplot of air temperature against water temperature, with the points whose air temperature was imputed in attempt 1 or attempt 2 in a different color from the rest.

Hint: Before Question 1.3, save which rows are missing in a Boolean column, then pass it to hue=.

2. Living Conditions (19 points)

This section looks at the conditions the fish lived in at different places and times. Use the dataset with the air temperatures imputed in Section 1.

2.1 Temperatures in August (5 points)

With a single groupby() statement, find the minimum, mean, standard deviation, and maximum of both air temperature and water temperature for each project, using only the rows from August (Month 8).

Hint: Named aggregation, from Data Aggregation, takes any number of name=("column", "statistic") pairs in one agg() call, so all eight results fit in a single statement.

2.2 Regions by latitude (4 points)

Use pd.cut() to create a column Region from Start Latitude:

  • Southern for a latitude below 42.4,
  • Central for a latitude from 42.4 to 42.8,
  • Northern for a latitude above 42.8.

Show how many rows fall in each region. Rows with a missing latitude get a missing Region, and the groupby() questions below leave them out.

2.3 Yearly temperature trend by region (8 points)

Make a line plot of the maximum air temperature and the maximum water temperature in each Month for each Region. Put the month on the horizontal axis and the temperature on the vertical axis, use a different color for each region, and a different line style (solid or dashed) for air and water.

Hint: Compute the maxima with groupby(), then reshape them with melt(), from Data Reshaping, so that air and water are values of one column you can pass to style=.

2.4 What the plot shows (2 points)

Does anything in the plot surprise you? Why or why not?

3. Fish Diversity (34 points)

Now turn to the fish themselves. Keep using the Region column from Question 2.2.

3.1 Top three species in each region (8 points)

Find the three Species with the largest total Number Captured in each region.

Hint: Total the catches by region and species, sort them, and keep the first rows of each region with groupby().head(), from Data Aggregation.

3.2 How widely species are spread (8 points)

Are some species found only in some regions? Make a plot of how many species were captured in all three regions, how many in exactly two, and how many in only one.

3.3 Species found in only one region (9 points)

What percentage of all species were captured only in the Southern region? Only in the Central region? Only in the Northern region?

Hint:

  1. Find the number of distinct regions in which each species is found.
  2. Keep the rows of the species found in only one region.
  3. Group those rows by region, count the unique species in each group, and divide by the total number of distinct species.

3.4 Turbidity and catch size (5 points)

Turbidity (Turbidity (ntu)) measures how cloudy the water is. In each region, is there a linear association between turbidity and Number Captured? Treat a correlation larger than 0.5 in magnitude as a linear association.

Hint: df.groupby("Region")[["col_a", "col_b"]].corr() returns one correlation matrix per region, stacked into one table with a two-level row index: the region on the outer level and the column name on the inner, as in the two-level index of Data Aggregation. The off-diagonal entry of each region’s 2 × 2 block is that region’s correlation.

3.5 Fish lengths (4 points)

The length of the fish caught is given by Maximum (mm) and Minimum (mm). For each region, find the largest Maximum (mm) and the smallest Minimum (mm). Which region has the widest range of fish lengths?

4. GDP, Surplus, and Compensation (15 points)

Three files describe the economy of each US state from 1997 to 2020, each with a different shape:

  • data/Real GDP.csv has one row per state and one column per year.
  • data/Surplus.csv has one row per year and one column per state.
  • data/Compensation.csv has one row per year, state, and Description, where Description is either Compensation (millions of dollars) or Chain-type quantity indexes for real GDP, and the number is in value.

Questions 4.1–4.4 combine them into one dataset with one row per state and year, holding the state, the year, and four values: GDP, surplus, compensation, and the chain-type quantity index.

The starter supplies the code that reads the four files:

gdp = pd.read_csv("data/Real GDP.csv")
surplus = pd.read_csv("data/Surplus.csv")
compensation = pd.read_csv("data/Compensation.csv")
region_mapping = pd.read_csv("data/State_region_mapping.csv")

4.1 Melt the GDP data (3 points)

Melt gdp to one row per state and year, with columns State, Year, and GDP.

Hint: Besides State and the year columns, gdp has a Description column that holds the same label in every row. Drop it first with gdp.drop(columns="Description"); otherwise melt() treats it as one more year column. The year column names become strings such as "1997". Convert the new Year column with astype(int) so it matches the integer years in the other files.

4.2 Melt the surplus data (3 points)

Melt surplus to one row per state and year, with columns Year, State, and Surplus.

4.3 Pivot the compensation data (3 points)

Pivot compensation to one row per state and year, with one column for each Description.

Hint: Each state, year, and Description has exactly one value, so this reshape only rearranges values: use pivot() from Data Reshaping, with index=["State", "Year"], columns="Description", and values="value". Then reset_index() turns State and Year back into columns, ready for the merge in Question 4.4.

4.4 Merge the three datasets (1 point)

Merge the three results from Questions 4.1–4.3 on State and Year. Show the shape of the combined dataset.

4.5 GDP over time by region (5 points)

Merge region_mapping with the combined dataset. Make a line plot of the mean GDP of each of the five regions in each year, without a confidence interval. Which two regions seem to have grown the least in GDP from 1997 to 2020?
