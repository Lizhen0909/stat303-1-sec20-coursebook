1. Missing Value Imputation (47 points)

data/Housing_missing_price.csv and data/Housing_complete.csv describe the same 545 houses: their area, bedrooms, bathrooms, and other features, and their price. The two files are identical except that some prices are missing in Housing_missing_price.csv. You will try several ways to impute the missing prices, then use Housing_complete.csv to check how close each method came, as Data Cleaning did with GDP per capita.

You cannot use Housing_complete.csv to impute a price. Impute as if you did not have it, and use it only afterwards, to score the imputation. Each method starts from the original housing_missing_price: store its imputed prices in a new Series rather than overwriting the price column.

The starter supplies the code that reads the data:

housing_missing_price = pd.read_csv("data/Housing_missing_price.csv")
housing_complete = pd.read_csv("data/Housing_complete.csv")

and a function, as in Data Cleaning, that plots imputed prices against the true prices and returns the RMSE. Use it in Questions 1.4, 1.6, and 1.7:

def score_imputation(imputed_price, true_price, method):
    """Plot imputed prices against the true prices, and return the RMSE.

    Pass only the rows whose price was missing, for example
    filled_price.loc[index_null_price] and housing_complete.loc[index_null_price, "price"].
    """
    rmse = np.sqrt(((imputed_price - true_price) ** 2).mean())

    fig, ax = plt.subplots(figsize=(6, 4.5), layout="constrained")
    ax.scatter(true_price, imputed_price, s=50)
    ax.axline((0, 0), slope=1, color="gray", linestyle="--", label="perfect guess")
    ax.xaxis.set_major_formatter("${x:,.0f}")
    ax.yaxis.set_major_formatter("${x:,.0f}")
    ax.set(xlabel="True price", ylabel="Imputed price",
           title=f"{method}: RMSE = ${rmse:,.0f}")
    ax.legend()
    plt.show()
    return rmse

Bonus: Choosing \(K\) by Cross-Validation (10 points, optional)

This is an optional question with no partial credit. You will get points only if your solution is completely correct. We advise you to attempt it only when you are done with the rest of the assignment. Loops are allowed.

In Data Cleaning, KNN imputation used a number of neighbors, \(K\), picked by hand, and the chapter noted that choosing it properly uses cross-validation, which the next course covers. This question walks you through a simple version. Cross-validation hides some of the prices you do know, imputes them, and measures how close the guesses came; repeating this so every known price is hidden once gives a fair score for each \(K\) without touching the truth you are trying to predict. Here you will choose \(K\) from the data with 10-fold cross-validation, then use it to impute the missing prices. You cannot use Housing_complete.csv to choose \(K\).

  1. Keep the rows of housing_dummy whose price is known, and reset their row labels with reset_index(drop=True), which renumbers the rows 0, 1, 2, … and discards the old labels; call the result housing_known. Rescale every column of housing_known to run from 0 to 1 with MinMaxScaler. Split the rows into 10 folds in order: the first tenth of the rows is fold 1, the next tenth fold 2, and so on. np.array_split(np.arange(n), 10) returns the row positions of each fold for n rows (NumPy documentation).

  2. For each \(K\) from 1 to 50, and for each fold: set the fold’s prices to missing, fill them with KNNImputer(n_neighbors=K), convert the filled prices back to dollars with the scaler’s inverse_transform(), and compute the RMSE against the fold’s true prices. Average the 10 RMSEs to get the cross-validation RMSE for that \(K\). Plot the cross-validation RMSE against \(K\), and report the \(K\) with the lowest value.

  3. Impute the missing prices of housing_dummy with KNN and that \(K\), using the scaler fitted in (a): fit_transform() learns each column’s range and rescales it, while transform() rescales with the range it already learned, so call scaler.transform(housing_dummy). Then score the imputation with score_imputation(). Is it more accurate than the methods in Section 1?
