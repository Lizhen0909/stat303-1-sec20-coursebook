# Assignment E project kit

This folder belongs inside your course folder:

```text
stat303-1/
└── assignments/
    └── assignment-e/    ← this folder
```

Extract the ZIP, move `assignment-e` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_e.ipynb`, keeping it beside `data/`, and select the course `.venv` as its kernel.

Complete instructions, points, and submission requirements are on the coursebook Assignment E page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20E.html

The `data/` folder holds the two files the assignment reads: `movies.json` (3,201 movies with their gross, budget, release date, genre, director, and ratings, from the [Vega datasets](https://github.com/vega/vega-datasets)) for Sections 1–4, and `sp500.csv` (daily S&P 500 prices, 2000–2022) for the optional bonus. The notebook starts without saved outputs or completed answers.
