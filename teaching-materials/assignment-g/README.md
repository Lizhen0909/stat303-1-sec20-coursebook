# Assignment G project kit

This folder belongs inside your course folder:

```text
stat303-1/
└── assignments/
    └── assignment-g/    ← this folder
```

Extract the ZIP, move `assignment-g` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_g.ipynb`, keeping it beside `data/`, and select the course `.venv` as its kernel.

Complete instructions, points, and submission requirements are on the coursebook Assignment G page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20G.html

The `data/` folder holds the five files the assignment reads: `Canadian_Fish_Biodiversity.csv` (a 2013 survey of fish populations in Ontario, Canada) for Sections 1–3, and `Real GDP.csv`, `Surplus.csv`, `Compensation.csv`, and `State_region_mapping.csv` (US state economic data, 1997–2020, and each state's region) for Section 4. The notebook starts without saved outputs or completed answers.
