# Assignment F project kit

This folder belongs inside your course folder:

```text
stat303-1/
└── assignments/
    └── assignment-f/    ← this folder
```

Extract the ZIP, move `assignment-f` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_f.ipynb`, keeping it beside `data/`, and select the course `.venv` as its kernel.

Complete instructions, points, and submission requirements are on the coursebook Assignment F page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20F.html

The `data/` folder holds the three files the assignment reads: `Housing_missing_price.csv` and `Housing_complete.csv` (545 houses with their features and price; the first has some prices removed) for Section 1 and the bonus, and `house_features_and_price.csv` (275 houses with their age, distance to the metro, nearby convenience stores, location, and price) for Sections 2 and 3. The notebook starts without saved outputs or completed answers.
