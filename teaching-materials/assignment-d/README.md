# Assignment D project kit

This folder belongs inside your course folder:

```text
stat303-1/
└── assignments/
    └── assignment-d/    ← this folder
```

Extract the ZIP, move `assignment-d` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_d.ipynb`, keeping it beside `data/`, and select the course `.venv` as its kernel.

Complete instructions, points, and submission requirements are on the coursebook Assignment D page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20D.html

The `data/` folder holds the four files the assignment reads: `colorado_coordinate_grid.txt` (10,000 candidate sensor locations on a latitude-longitude grid over Colorado) and `colorado.jpg` (the map `sensor_viz()` draws on) for Section 1, and `starbucks-menu-nutrition-drinks.csv` and `starbucks_DrinkType_USStates.csv` for Section 3. The notebook starts without saved outputs or completed answers.
