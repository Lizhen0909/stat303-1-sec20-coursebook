# Assignment B project kit

This folder belongs inside the course folder you build in Assignment B:

```text
stat303-1/
└── assignments/
    └── assignment-b/    ← this folder
```

Extract the ZIP, move `assignment-b` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_b.ipynb`, keeping it beside `data/`.

Complete instructions, points, and submission requirements are on the coursebook Assignment B page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20B.html

The CSV contains six fictional library-branch visit counts for one illustrative day. It is not a real survey. Pandas and plotting code are supplied so the assignment assesses your setup workflow and interpretation.

Create the course `.venv` and `requirements.txt` at the root of `stat303-1` as directed, not in this folder. Do not submit the environment. The notebook starts without saved outputs or completed answers.
