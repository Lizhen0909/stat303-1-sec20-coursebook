# Assignment C project kit

This folder belongs inside your course folder:

```text
stat303-1/
└── assignments/
    └── assignment-c/    ← this folder
```

Extract the ZIP, move `assignment-c` into `stat303-1/assignments/`, and open `stat303-1` (not this folder) in VS Code. Work in `assignment_c.ipynb`, keeping it beside `data/`, and select the course `.venv` as its kernel.

Complete instructions, points, and submission requirements are on the coursebook Assignment C page:
https://lizhen0909.github.io/stat303-1-sec20-coursebook/Assignment%20C.html

The `data/` folder holds the four files the assignment reads: `social_indicator.txt` (Sections 1 and 2), `conditions.csv` and `patients.csv` (Section 3, synthetic patient records), and `stat303_survey.csv` (the bonus question). The notebook starts without saved outputs or completed answers.
